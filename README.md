# 🍔 Project Hamburgueria

Bem-vindo ao repositório do **ProjectHamburgueria**! Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web front-end.

---

## 🚀 Tecnologias Utilizadas

Durante o desenvolvimento deste projeto, foram utilizadas as seguintes tecnologias:

* **HTML5**: Estruturação semântica das páginas.
* **CSS3**: Estilização, layout e design responsivo.
* **JavaScript**: Interatividade e dinamismo na interface.
* **Git e GitHub**: Controle de versão e hospedagem do código.

---

## 📌 Funcionalidades

* 📱 Layout responsivo (adaptado para telemóveis, tablets e computadores).
* 🍔 Apresentação visual de itens de menu/hambúrgueres.
* 🛒 Estrutura preparada para navegação intuitiva.
